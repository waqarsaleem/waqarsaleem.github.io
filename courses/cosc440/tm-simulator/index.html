The machine starts in state 0 with its head on the first input symbol. The tape is infinite in both directions. It holds the start marker ▷, then the input, and the null symbol ϕ everywhere else.

How to use this tool

There are two ways to start.

  • Try an example. In step 1, choose an example machine and press "Load example". Then go to step 3 and press "Step" to watch it work one step at a time, or "Run" to watch it run by itself.
  • Build your own machine. In step 1, enter the number of states and any extra symbols, and press "Update table". In step 2, fill in the table: for each state and each symbol it might read, choose the next state, the symbol to write, and the action. In step 3, type a tape input and press "Step".

Cells of the table may be left empty and filled in later. The state diagram in step 3 redraws as you fill in the table. "Save machine to file" in step 1 keeps your machine so that you can load it again later.

1. Set up the machine

The alphabet always contains 0, 1, ▷, and ϕ. Type any other symbols one after another with no spaces, for example ab#.

2. Transition table

Each cell has three boxes: the next state, the symbol to write, and the action (L left, R right, S stay, H halt). Cells may be left empty and filled in later.

Keyboard entry
  • Press Tab to move from box to box, and type a character to choose a value. For example, 1 Tab 0 Tab R Tab enters "go to state 1, write 0, move right" and moves to the next cell.
  • In the first box, type x to mark the cell "cannot occur", or * for a halting transition. Choosing H as the action also sets the state to *.
  • In the second box, type > for ▷ and _ for ϕ.
  • Press Delete or Backspace to clear a cell.

A dashed border marks an incomplete cell. A striped cell is marked "cannot occur". A thick border marks the cell the machine will use next.

3. Run the machine

Any symbols of the alphabet except ▷ and ϕ. Changing the input restarts the run.

State diagram

Each arrow is labeled a / b, A: on reading a, write b and take action A. A short arrow ending in a filled square is a halting transition. The current state has a double outline, and the transition just taken is drawn thicker with its label in bold. On a large screen, the tape, buttons, and status stay at the top of the window while you scroll.

States can be dragged with a mouse or finger to tidy the picture. Dragging changes only the layout, not the machine.
