Test whether a string matches a regular expression, and list example strings that match or do not match. A string matches only if the whole string is described by the expression. A symbol is a letter or digit other than e. Use | for union, * for repetition, parentheses for grouping, and e for the empty string. Spaces are ignored.

How to use this tool

There are two ways to start.

  • Try an example. In step 1, choose an example and press "Load example". Then go to step 2 to test a string, or to step 3 to list strings.
  • Use your own expression. In step 1, type your expression and press "Check expression" to see whether it is valid. Then go to step 2 or step 3.

Changing the expression or the alphabet in step 1 clears the results in steps 2 and 3.

1. Regular expression

For example (0|1)*01. Type e for the empty string.

The alphabet always includes the symbols in the expression. Add others by typing them one after another, for example 01. They affect only the non-matching strings listed in step 3.

3. List example strings

List strings that match the expression and strings that do not, shortest first. Strings of the same length are in alphabetical order, with digits before letters.

Strings longer than 20 symbols are never listed.
